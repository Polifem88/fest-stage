# ФЭСТ · Большая сцена — интерактивная 3D-планировка

Зал, сценическая коробка, галереи, механика (штанкеты, софиты, противовесы) и световое оборудование Большой сцены театра ФЭСТ. Работает в браузере, без установки.

- **Сайт:** откройте `index.html` (на GitHub Pages — главная страница) — он сам предложит версию для компьютера или телефона.
- **Без интернета:** файлы `desktop.html` и `mobile.html` из сборки открываются двойным кликом.

## Что умеет

- Ход штанкетов и софитов (слайдеры, ввод числа, перетаскивание прямо в 3D), противовесы на левой стене.
- Сценический, дежурный и зальный свет: группы, «соло», отдельные приборы, плотность дымки; карточка прибора с паспортными данными.
- Виды: из зала, с пульта, план, план сцены крупно, разрез, со сцены, с галерей.
- Режим «Чертёж»: экспликация приборов, масштабная линейка, размеры, сетка 1 м — для райдера; скриншот в PNG.
- Ссылка с сохранённым состоянием (высоты, свет, вид) и сохранение в файл.

> Наведение приборов в модели условное; паспортные данные — по открытым данным производителей. Уточняйте в световом цехе.

## Для разработчика

```powershell
cd app
npm install
npm run dev      # http://localhost:5173/
npm run check    # юнит-тесты + сборка + браузерные тесты (скриншоты, FPS, офлайн-открытие)
npm run build    # app/dist/: index.html, desktop.html, mobile.html — каждый одним файлом
```

Все размеры, механика и приборы — в `app/src/config/` (единый источник правды). Публикация на GitHub Pages — автоматически при каждом push в `master` (`.github/workflows/pages.yml`).
