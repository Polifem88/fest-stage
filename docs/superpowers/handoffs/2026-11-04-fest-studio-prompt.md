Реализуй черновик модели «Студии мультимедиа» (`studio`) строго по готовому плану. Исследование, интервью и проектирование уже сделаны в прошлой беседе, повторно их не проводи. Работа идёт в ветке `studio`, она уже создана.

**Прочитай до начала работы, по порядку:**
1. `docs/superpowers/handoffs/2026-11-04-fest-studio-handoff.md` — передача контекста: режим работы, состояние репозитория, решения интервью, карта кода, подводные камни, точки остановки.
2. `docs/superpowers/specs/2026-11-04-fest-studio-draft-design.md` — спецификация, единственный источник размеров и решений.
3. `docs/superpowers/plans/2026-11-04-fest-studio-draft.md` — план, задачи 0–9.
4. `GEMINI.md` и навыки проекта: `.agents/skills/venue-module-authoring` (основной), `playwright-webgl-qa`, `mobile-cad-touch-ux`.
5. Навык `superpowers:executing-plans`. Для каждой задачи также применяй `test-driven-development` и `verification-before-completion`.

**Режим:**
- Все задачи выполняешь сам, по порядку, **без субагентов**. Единственное исключение — финальное ревью ветки субагентом уровня **pro** (Task 9 Step 4), и только после моего подтверждения.
- Начни с задачи 0: эталон паритета со свежей сборки `master`, самопроверка 100 %, возврат в `studio`.
- После каждой задачи:
  - тесты зелёные;
  - коммит на русском в стиле истории репозитория;
  - отметь выполненные шаги в файле плана (`- [x]`);
  - проверь правило 10-го коммита: если `git rev-list --count HEAD % 10 == 0`, запусти `cd app; npm.cmd run backup` и убедись, что совпадение 100 %. Ближайший — коммит №70.
- Если спецификация и реальный код расходятся или находится непредусмотренное — не додумывай размеры. Остановись и спроси меня: по одному вопросу, со своей рекомендацией.

**Остановки, на которых ждёшь меня:**
- после снимков студии (Task 8 Step 1): ключевые кадры и список допущений для сверки с фото;
- перед финальным ревью субагентом pro;
- запуск локального сервера для моей проверки (Task 9 Step 3);
- слияние `studio` → `master` и `git push` — только после моего явного «ок».

**Готово, когда:**
- `cd app; npm.cmd run check` зелёный;
- паритет Большой, Камерной и Сцены под крышей — 100 % (Сцена под крышей с чёрными фермами);
- студия открывается по `#v=studio` с пометкой «черновик»;
- снимки студии просмотрены мной;
- документация обновлена;
- бэкапы проверены.
