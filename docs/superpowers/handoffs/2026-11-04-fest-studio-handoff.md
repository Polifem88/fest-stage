## 5. Подводные камни

1. **Побайтовый паритет Сцены под крышей после переноса ферм (Task 1).** Сохранить порядок труб: пояса → 4 грани по очереди → торцевые рамки; у стоек — 4 пояса → грани k = 0…3. Сохранить арифметику: высоты узлов `y0 + ((y1 − y0)·i)/n` при `y0 = 0` дают те же числа, что `(T.y0·i)/n`. Тот же `tag: 'trusses'`, тот же порядок вызовов `batch.add` (фермы, затем плиты).
2. **Материалы — только в конец.** Порядок создания = порядок отрисовки готовых сцен. Иначе паритет снимков упадёт.
3. **UV панелей.** Модули неквадратные (1,22 × 2,42 и 1,22 × 0,62) и с разной привязкой по стенам. `worldUV` так не умеет — UV считает `panelUV` студии, геометрии кладутся с `{ uv: false }`. Для x-стен развёртка идёт по `z = −d`.
4. **Циклорама односторонняя, лицом внутрь.** С `+d` (из-за стены за ней) её не видно. Поэтому «Общий вид» снимаем со стороны операторской. Пол циклорамы приподнят на `FLOOR_LIFT` ≈ 0,003 против z-fighting.
5. **«Чертёж»** строит `EdgesGeometry` по каждому статическому мешу. На дугах это может дать штриховку — смотреть снимок `+bp`. Пустые меши не добавлять: у геометрии без вершин рёбер не построить.
6. **Площадка без приборов** — первый такой случай в проекте. Проверить: ссылку (`fn: 0`), общий GLB, `stage.stageState()` на пустом списке, смену сцен туда и обратно. Ошибок в консоли быть не должно (`expectNoErrors`).
7. **Ориентация по фото.** Циклорама — у дальней стены. Операторская с окном — над козырьком у противоположной. Выход — под козырьком, в правом углу при взгляде на циклораму. Техническая дверь — на правой стене. Вертикальная вставка — в левом углу у операторской.
8. **Положения дежурки, кассет и диффузоров, высота циклорамы, окно и низ вставок у циклорамы** — оценки по фото (`assumption: true`). На просмотре снимков (Task 8) сверить с фото и показать заказчику.
