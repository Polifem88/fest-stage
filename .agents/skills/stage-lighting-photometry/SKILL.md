# Stage Lighting & Photometry Engineering

Руководство по моделированию театрального света, фотометрическим расчётам, рендеру лучей в Three.js и подготовке светотехнической документации.

## 1. Фотометрические расчёты и геометрия луча

### Диаметр светового пятна
При направлении луча на поверхность под углом падения $\alpha$ (где $\alpha = 0$ — нормаль к поверхности) с расстоянием $L$ от источника до точки пересечения и углом раскрытия луча $\theta$:
* Для нормального падения:
  $$D = 2 \cdot L \cdot \tan\left(\frac{\theta}{2}\right)$$
* Для косого падения пятно превращается в эллипс с главными осями:
  $$D_{\text{minor}} \approx 2 \cdot L \cdot \tan\left(\frac{\theta}{2}\right), \quad D_{\text{major}} \approx \frac{D_{\text{minor}}}{\cos(\alpha)}$$
* Расстояние броска луча (Throw distance):
  $$L = \sqrt{(X_{\text{fixture}} - X_{\text{target}})^2 + (Y_{\text{fixture}} - Y_{\text{target}})^2 + (Z_{\text{fixture}} - Z_{\text{target}})^2}$$

### Освещённость (Закон обратных квадратов)
$$E = \frac{I \cdot \cos(\alpha)}{L^2}$$
где $I$ — осевая сила света (канделы), $E$ — освещённость (люкс).

## 2. Моделирование света в Three.js (`systems/fixtures.js`)

Общая система освещения (`FixtureSystem` в `app/src/systems/fixtures.js`) отрисовывает приборы всех площадок каталога:

1. **Мягкое смешивание световых пятен (Blend Equation):**
   * Чтобы десятки пересекающихся лучей в центре сцены не приводили к пересвету («выбитому белому листу»), материал световых пятен на планшете настраивается через уравнение максимума:
     ```javascript
     spotMaterial.blending = THREE.CustomBlending;
     spotMaterial.blendEquation = THREE.MaxEquation;
     spotMaterial.blendSrc = THREE.OneFactor;
     spotMaterial.blendDst = THREE.OneFactor;
     ```
2. **Проекция и обрезка пятен по полу (`venue.fixtures.floor`):**
   * Пятна света от приборов программно обрезаются по границам игрового планшета и авансцены, не проваливаясь под пол.
   * Контракт пола `floor` предоставляет функции `trace(p, dir)`, `zone(p)`, `clip(mat)`.
   * Для типовых залов используется хелпер `rectFloor({ x0, x1, d0, d1, y, maxDist })` из `systems/fixtures.js`.
   * Для сложного пола с авансценой реализуется индивидуальная шейдерная обрезка с обязательным уникальным ключом кэша:
     ```javascript
     mat.customProgramCacheKey = () => 'pool-venue-unique-id';
     ```
3. **Объёмные лучи и дымка (Haze):**
   * Конусы света рендерятся полупрозрачной конической геометрией с мягким шейдером затухания к основанию и краям.
   * Плотность сценической дымки регулируется коэффициентом непрозрачности (`state.hazeDensity`), влияющим на видимость лучей в пространстве.

## 3. Модель данных прибора и единые справочники

Архитектура разделяет общетеатральный справочник оборудования и конфигурацию развеса конкретной площадки:

1. **Общий справочник типов театра (`app/src/library/fixtureTypes.js`):**
   * Содержит общее описание моделей приборов (`TYPES`): форму упрощённого корпуса (`shape`: `spot`, `wash`, `beam`, `ledpar`, `profile`, `fresnel`, `par`, `follow`), масштаб, угол раскрытия по умолчанию `beam`, флаг лампового диммерного управления `lamp: true`.
   * Площадка может добавить собственные не уточнённые типы через `venueTypes(localTypes)` строго в конец словаря.
2. **Паспорта производителей (`app/src/library/specs.js`):**
   * Содержат спецификации моделей (`SPECS`): мощность `power`, источник света `source`, зум `zoom`, цветопередачу `color`, вес `weight`, протокол `dmx`, степень защиты `ip`, ссылку на документацию `url`.
3. **Конфигурация развеса площадки (`app/src/venues/<id>/config/fixtures.js`):**
   * Каждый прибор в массиве `FIXTURES` описывается объектом:
     ```javascript
     {
       no: '38',                     // уникальный номер прибора на площадке
       group: 'C1',                  // группа (софит 1, мост, вынос, ложа, прострел)
       type: 'SPOT585',              // ключ из library/fixtureTypes.js или localTypes
       pos: [x, y, d],               // координаты подвеса (d = -z)
       mount: { on: 'S1', x, y, d }, // привязка к подвижному софиту (или on: null на ферме)
       aim: { x: ax, y: 0, d: ad },  // точка наведения луча на планшете
       beam: 16,                     // угол раскрытия луча (градусы)
       color: '#ffffff',             // цвет луча (по умолчанию тёплый)
     }
     ```

## 4. Панель управления и логика режимов

1. **Режим «Соло» (Solo):**
   * Позволяет одним кликом погасить весь сценический свет и изолировать отдельную группу (например, только выносной мост 1 или только прострельные стойки).
   * Повторный клик по кнопке Solo восстанавливает предыдущую световую картину без потери состояния тумблеров.
2. **Карточка прибора:**
   * Открывается при клике на 3D-модель прибора или по номеру в поиске/панели.
   * Отображает: паспортные характеристики производителя из `specs.js`, высоту подвеса над планшетом, наведение, расстояние по лучу до пола и рассчитанный диаметр светового пятна.
3. **Цветовая палитра для режима чертежа:**
   * В режиме экспликации каждый тип оборудования окрашивается в строго контрастный HEX-цвет из палитры `typeColors(types)` (`systems/fixtures.js`) для мгновенной читаемости на чертеже. Порядок назначения цветов зависит от порядка ключей в `types`, поэтому локальные типы сцены всегда добавляются в конец.
