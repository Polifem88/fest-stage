# Шаблон «чёрный кабинет» (`venues/_template`)

Параметрический построитель площадки **без портала и без подвижной механики**: прямоугольный
зал с чёрными стенами и потолком, ровная игровая площадка, ряды кресел, неподвижные
треугольные фермы с жёсткими подвесами к потолку, лампы дежурного и зального света.
Вся геометрия строится **только из объекта-конфигурации** (`cfg`) — в коде шаблона нет
размеров конкретной площадки.

Камерная сцена ([`venues/fest-chamber`](../fest-chamber)) начиналась с этого шаблона (и использует его `trussGeometry` / `tubeBetween`), но выросла в самостоятельный архитектурный модуль со ступенчатым амфитеатром, левым карманом, нишей выхода и кастомным экспортом 2D/3D DXF и GLB.

## Что внутри

| Файл | Что делает |
|---|---|
| `layout.js` | Чистая раскладка без Three.js: глубины ферм `trussDs`, пролёт `trussXRange`, пояса `trussChords`, подвесы `hangerXs`, ряды и места `rowFrontD` / `seatLayout` / `seatCount`. Её же используют развес приборов и юнит-тесты. |
| `build.js` | `buildBlackBox(ctx, cfg)` — строит всё сразу; по отдельности: `trussGeometry(...)` (3 пояса + раскосы «зигзагом» на трёх гранях + торцевые рамки, одна склеенная геометрия), `buildSeats`, `buildEmitters`, `tubeBetween`. |
| `overlays.js` | `blackBoxViews(cfg)` — готовые виды; `blackBoxDims(cfg)` — список размеров; `blackBoxGrid(labels, cfg)` — сетка 1 м с осями и оцифровкой; `blackBoxOverlays` — оба наложения для движка; `blackBoxAmbient(plan, cfg, dutyRows)` — дежурный и зальный свет. |
| `index.js` | Реэкспорт всего перечисленного. |

Статика (пол, стены, потолок, фермы, подвесы) идёт через `ctx.batch` — по одному мешу на пару
«слой + материал». Кресла — два `InstancedMesh` (`seatsFabric` / `seatsFrame`, их узнаёт режим
«чертёж»). На всю площадку выходит ≈ 20 вызовов отрисовки и ≈ 25 тыс. треугольников.

## Как сделать новую площадку

1. **Для новой простой площадки** возьмите функции шаблона `venues/_template/` (или обратитесь к `venues/fest-chamber` как к расширенному эталону нелинейной геометрии).
2. **Размеры** — `config/dimensions.js`, объект-конфигурация:
   - `room: { x0, x1, d0, d1, ceiling }` — внутренний объём зала (X — поперёк, d — вглубь, z = −d);
   - `stage: { d0, d1 }` — игровая площадка по глубине; `d = 0` — нулевая линия площадки
     (у Камерной — передний край площадки), опишите её в шапке файла;
   - `hall` — ряды: `rows`, `blocks` (кресел в блоках ряда, напр. `[8, 8]`), `aisle` (проход между
     блоками), `seatPitch`, `rowPitch`, `firstRowGap`, `riser` (подъём ряда; 0 — ровный пол),
     `seatDepth`, `eyeY`;
   - `trusses` — фермы: `count`, `step`, `center` (необязательно; по умолчанию — середина зала),
     `side` (сторона треугольника по осям поясов), `tube`, `bottomY` (ось нижних поясов),
     `apexUp`, `wallGap`, `lacingPitch`, `hangerStep`, `hangerInset`, `hangerTube`, `plate`, `seg`, `segMobile`;
   - `emitters` — где висят лампы дежурного (`duty`: номера ферм и X) и зального (`house`: сетка дисков на потолке) света;
   - `ambient` — цвет и яркость дежурного/зального света (подбираются по снимкам);
   - необязательно: `materials` / `layerOf` (переназначить материал или слой части), `views` (поправить
     или добавить вид), `viewMargin`, `planLegendPad`, `planTopPad`, `gridLabelStep`, `zeroLineLabel`.
   Всё, что не дано заказчиком, помечайте комментарием `assumption: true`.
3. **Приборы** — `config/fixtures.js`: типы — из общего справочника `library/fixtureTypes.js`
   (свой тип — через `venueTypes({...})`, в конец), группы, наборы кнопок, список приборов.
   Крепление на ферме — `mount: { on: null, x, y, d }` (механики нет), помогает `onTruss(ферма, x, пояс)`.
   Номера приборов уникальны.
4. **Модуль** — `index.js`: поменяйте `id`, `name`, `status`, `meta`, `caps`, `layers`
   (порядок слоёв — порядок битов в ссылке: у опубликованной площадки только добавлять в конец),
   `lightPlans`, `camera.maxDistance`. Пол для пятен света — `rectFloor(...)` из `systems/fixtures.js`.
5. **Каталог и реестр** — описание сцены в `venues/catalog.js`:
   `{ id: '<id>', name: '…', short: '…', status: 'draft', type: 'Чёрный кабинет', seats: N }`;
   загрузчик — в словарь `LOADERS` файла `venues/registry.js`: `<id>: () => import('./<папка>/index.js')`.
6. **Тесты** — `tests/unit/venues.contract.test.js` проверит контракт новой площадки сам; свои
   проверки размеров — по образцу `tests/unit/chamber.test.js`. Затем из `app`:
   `npx vitest run`, `node scripts/build.mjs`, снимки всех видов (обычный, «чертёж», размеры и сетка) —
   посмотрите их глазами.

## Ограничения шаблона

- Пол ровный, на одном уровне для площадки и зрителей (подъём рядов — только ступенями `riser`).
- Фермы — только поперёк зала (вдоль X), с равным шагом; механики нет (`rigging: null`).
- Ортогональные виды подобраны под экран компьютера (≈ 1,4 : 1); в книжной ориентации телефона
  план шире экрана — его можно сдвигать и масштабировать.
