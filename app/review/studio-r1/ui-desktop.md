   - **Предложение по исправлению:** в `app/src/venues/fest-studio/build/overlays.js` либо разместить подписи `Глубина` и `ФП` посередине между делениями сетки (например, `t = 0.50` / `0.50`? для `Глубина` `[-8.60; 4.00]` середина `d = -2.30` между `-3` и `-2`; для `ФП` `[-3.20; 1.80]` середина `d = -0.70`, но там `-1`..`0` -> `t = 0.54` даёт `d = -0.50` ровно между `-1` и `0`!), а ещё надёжнее — вынести `d`-размерные цепочки на разрезе на разный уровень по `Y` или сдвинуть `t` так, чтобы оба жёлтых шильдика попадали строго в середины метровых ячеек (`d = -2.50` и `d = -0.50`) или ниже пола `Y < 0` при `dir === 'side'`.
